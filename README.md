# Explainable Network Intrusion Detection System (NIDS)

**XGBoost + SHAP Explainability** — Flask Backend + Vanilla JS Frontend

---

## 🚀 Quick Start

### Option 1: Double-click `run.bat` (Windows)
```cmd
run.bat
```

### Option 2: Python launcher
```bash
python run.py
```

### Option 3: Manual
```bash
cd flask_backend
python train.py   # Only first time
python app.py
```

Then open **http://localhost:5050** in your browser.

## ✨ Features

### 4-Tab Interface
| Tab | Description |
|-----|-------------|
| **Overview** | Metric cards, clickable 6-stage pipeline, live detection feed (auto-runs inference every 2.5s) |
| **Traffic Analysis** | Sample flow library (normal + 10 attack types), manual input form (41 features grouped), verdict card with confidence gauge, SHAP waterfall chart |
| **Model Training** | Hyperparameters, train/val/test split comparison (exposes overfitting), confusion matrix, recall by attack type |
| **SHAP Explainability** | Global feature importance bars, beeswarm/summary plot (top 12 features, colored by feature value) |

### API Endpoints
| Endpoint | Description |
|----------|-------------|
| `GET /api/meta` | Feature list, descriptions, categorical options, global importance, metrics |
| `GET /api/samples` | Curated test flows with ground-truth labels |
| `GET /api/pipeline` | 6-stage pipeline descriptions |
| `GET /api/shap_summary` | Pre-computed SHAP values for beeswarm plot |
| `POST /api/predict` | Input: 41 features → Output: prediction, probability, base_value, sorted SHAP contributions |

## 🎯 Model Performance

| Metric | Train | Validation | Test (KDDTest+) |
|--------|-------|------------|-----------------|
| Accuracy | ~100% | ~99% | **78.9%** |
| Precision | ~100% | ~99% | **97%** (attack) |
| Recall | ~100% | ~99% | **65%** (attack) |
| F1-Score | ~100% | ~99% | **78%** |
| ROC-AUC | ~1.0 | ~1.0 | **0.97** |

**Key insight**: Train/Val ~100% vs Test ~79% shows overfitting to known attacks. Test+ includes novel attack types (e.g., `guess_passwd` recall = 0%, `neptune` recall = 99.9%).

## 📝 Extending

- **Custom data**: Replace CSV loading in `train.py` with your flow data (adjust `COLUMNS` if needed)
- **Multi-class**: Change target to original attack labels + `objective: "multi:softprob"` in XGBoost
- **Production**: Use gunicorn + nginx (`gunicorn -w 4 -b 0.0.0.0:5050 app:app`)
- **New features**: Add to `COLUMNS`, `FEATURE_DESCRIPTIONS`, retrain
